#  Simulador de Grafos (Grafos App)

Una aplicación web interactiva desarrollada para la creación, edición y visualización de grafos, ideal para la simulación de redes y estructuras de datos.

##  Características

- **Lienzo Interactivo:** Creación intuitiva de nodos haciendo clic en el lienzo y conexión de aristas entre ellos.
- **Edición y Personalización:** Modificación de nodos y aristas con soporte para etiquetas y pesos.
- **Interfaz Moderna:** Diseño limpio en modo claro con indicadores de estado y estadísticas en tiempo real.
- **Herramientas de Limpieza:** Opciones para vaciar o reiniciar el lienzo rápidamente.

## Tecnologías Utilizadas

- **Vue.js** (Componentes con estilos `<style scoped>`)
- **SVG** (Para el renderizado dinámico de nodos y aristas)
- **CSS3 / Flexbox**
